claude-dev-tools · prototypes — not shipped code

html-visualize improvement prototypes

Two clickable pages exploring the proposed selection model, page chrome, and visual language. Both work in light and dark mode.

1 · Feedback mode — element-level targets

The reviewed document is a real proposal for this feature; every improvement it describes is live on the page.

  • Select any text — a single word is enough — and comment on it
  • ⊹ Pick element: click a list item, table row, or code line
  • Click a node in the Mermaid diagram to comment on the node itself
  • Comments live in a margin rail with numbered blue-pencil pins
  • Apply / Submit / View payload show the exact JSON that would POST

2 · Visualize mode — redesigned page & footer

Real numbers from the working tree: line counts, test suites, and the plugin's routing architecture.

  • Sticky table of contents with scrollspy
  • Stat tiles and a bar chart built to the dataviz mark specs, with hover tooltips
  • Collapsible, line-numbered code section
  • ✛ Point at… — reference a bar, row, tile, or diagram node as a chip in the message footer
  • Send shows the structured payload the references would produce

3 · Ask mode — progress, new widgets, unanswered flow

A real decision batch for this project: seven calls that shape the implementation PR. ?demo pre-fills half the form.

  • Progress dots in the top bar + a question index with answered state on wide screens
  • Every question has an “Explain this decision” disclosure in plain English
  • New widget kinds: comparison cards with pros/cons, a 1–5 scale, arrow-button ranking
  • Architecture question: Before/After Mermaid diagrams you agree or disagree to — nodes commentable
  • Anchored comments beyond the plain note: select text, 💬 an option row, or click a diagram node
  • Submit flags unanswered questions with jump links — partial submits allowed, never blocked
  • View payload shows the extended schema (scale → number, rank → array, comments with targets)

Theme sketch: “Proof” — blue pencil on a cool proof sheet. Chrome is a sans-serif instrument; the content is a serif artifact; everything the user adds is pencil blue. Diagrams need the Mermaid CDN once; everything else is self-contained.
