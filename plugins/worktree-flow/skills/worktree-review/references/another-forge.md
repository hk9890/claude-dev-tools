# Another forge

Run each `gh` step of `SKILL.md` with the forge CLI the project documents; with none documented, at the first field of step 1 that CLI cannot read, or at a later `gh` step it cannot run, stop and ask the user. Pass both reviews the local branch that step 1 puts at the PR's head (`git rev-parse --abbrev-ref HEAD`) in place of `<pr-number>`: they read a number as a GitHub PR, and the PR's head branch can have another name in this checkout. Pass the rules review that branch as `<remote>/<target>...<branch>`, after `git fetch <remote> +refs/heads/<target>:refs/remotes/<remote>/<target>`, with `<target>` the PR's target branch as the forge CLI prints it, else stop and ask the user: without it, it diffs against the default branch.
